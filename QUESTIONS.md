# Контрольные вопросы — практическая работа № 22

**Тема:** автозагрузка классов, абстрактные классы и свойства PHP.

### 1. Когда PHP вызывает автозагрузчик и что происходит, если файл не найден?

PHP вызывает зарегистрированные функции автозагрузки при первом обращении к пока неизвестному классу (например, `new User()` или при проверке типа класса с разрешённой автозагрузкой). Автозагрузчики вызываются по очереди. Если ни один не смог определить класс, то при попытке создать его возникает ошибка вида `Error: Class "User" not found`.

### 2. В чём преимущество `spl_autoload_register()` перед `__autoload()`?

`spl_autoload_register()` позволяет зарегистрировать **несколько** независимых автозагрузчиков и использовать стандартный современный механизм PHP. `__autoload()` устарел и удалён с PHP 8.0. Для новых проектов следует использовать `spl_autoload_register()` или загрузчик Composer.

### 3. Чем абстрактный класс отличается от интерфейса? Когда выбирать каждый вариант?

Абстрактный класс может хранить свойства, конструктор, константы, обычные методы с реализацией и абстрактные методы. Он подходит, когда несколько типов объектов относятся к **одной общей иерархии** и должны разделять состояние или код (`Shape`, `Employee`). У класса может быть только один родительский класс.

Интерфейс задаёт **контракт** публичных методов: что объект умеет делать, а не как это реализовано. Интерфейс выбирают, когда разные, возможно не связанные наследованием, классы должны иметь единый набор методов. Класс может реализовать несколько интерфейсов одновременно.

### 4. Можно ли создать экземпляр абстрактного класса и объявить абстрактное свойство?

Нельзя создать объект абстрактного класса напрямую: `new Shape()` приведёт к `Error: Cannot instantiate abstract class Shape`. Объекты создаются из конкретных классов-наследников, реализовавших все абстрактные методы. **Абстрактные свойства** в PHP 8.1 в обычном виде не поддерживаются: нужное свойство обычно задают в абстрактном базовом классе или требуют методы `get...()`/`set...()` через абстрактные методы.

### 5. Чем статическое свойство отличается от обычного и как к нему обратиться?

Обычное свойство относится к **конкретному объекту** (`$object->name`) и может быть разным у разных экземпляров. Статическое свойство относится к **классу**, его значение общее для объектов соответствующей иерархии. Внутри класса обращаются через `self::$count` или `static::$count`, снаружи — через `ClassName::$count`, **только если свойство доступно по модификатору** (`public`). В задании `Employee::$employeeCount` — `private`, поэтому извне использован метод `Employee::getEmployeeCount()`.

### 6. Что означает `readonly` и какие ограничения оно накладывает?

Свойство с `readonly` (PHP 8.1+) после инициализации нельзя переназначать. Обычно его значение устанавливается один раз в конструкторе. В задании 5 используется `public readonly string $title`, и попытка `$book->title = 'Другое название';` после создания объекта вызывает `Error: Cannot modify readonly property`. Нельзя изменять readonly-свойство и при помощи `unset()` после инициализации. Модификатор не делает автоматически неизменяемыми *объекты*, на которые такое свойство ссылается; он запрещает замену самой ссылки в свойстве.
